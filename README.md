# AZRA PROJECT Website

Modern, responsive corporate website for AZRA PROJECT.

## Included

- Responsive corporate landing page
- English / Turkish / Arabic language switcher
- RTL support for Arabic
- Services, operations, projects and contact sections
- Mobile navigation
- Contact email and phone actions
- No framework or build step required

## Local preview

Open `index.html` in a browser.

## Deployment

The site is ready for GitHub Pages or another static hosting provider.
